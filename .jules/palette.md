## 2026-09-02 - Form Accessibility and Input Classes
**Learning:** The default admin form components lack proper label-to-input associations, dynamic error roles, and use a non-existent `input-field` class instead of the standard `input` class defined in `index.css`.
**Action:** When working on admin forms, always explicitly link `<label>` and `<input>` elements using matching `htmlFor` and `id` attributes, ensure dynamic error messages have `role="alert"`, and use the standard `input` class for consistent styling.
